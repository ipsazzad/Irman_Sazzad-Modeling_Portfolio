# Econometrics Problem Sets (R & Stata)

This folder contains PhD econometrics coursework in R and Stata, covering fixed and random effects, GMM, logit and probit maximum likelihood, nonparametric and semiparametric regression, quantile regression, difference-in-differences, and instrumental variables, one problem set per file. Method detail across all coursework is available in the full portfolio write-up: https://ipsazzad.github.io
